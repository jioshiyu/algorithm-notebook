## 快速开始

```bash
# 运行任意一题的 Python 解
python problems/01-divide-and-conquer/count-pages/python/solution.py < 输入

# 编译并运行 C++ 解
g++ -O2 -std=c++17 problems/01-divide-and-conquer/count-pages/cpp/solution.cpp -o /tmp/a
/tmp/a < 输入

# 一题全检：样例 + 随机对拍 + 计时
python shared/check.py problems/01-divide-and-conquer/count-pages --stress 500
```

环境：Windows / Linux 均可；C++ 需要支持 C++17 的 g++ 或 clang++，Python ≥ 3.10。

## 仓库约定（摘要）

- 目录：`problems/<算法思想分类>/<题目 slug>/`，一题一目录，单处维护；
- 每题固定结构：`README.md`（题解）+ `cpp/`（解法）+ `python/`（移植）+ `tests/`（样例、暴力、随机生成器、对拍脚本）；
- 输入输出一律 **stdin/stdout**，样例放 `tests/samples/`；
- 所有解法必须通过：样例 → 随机对拍（与暴力参考解比对）→ 大规模计时；
- 详细规范见 [docs/guide.md](docs/guide.md)。
