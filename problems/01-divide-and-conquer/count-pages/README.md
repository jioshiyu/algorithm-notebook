# 1-1 统计数字问题（页码计数）

> 分类：分治 · 数位统计　|　来源：课程实验报告 1-1　|　难度：中等

## 题目

一本书的页码从 1 顺序编号到 n。统计所有页码中数字 `0` 到 `9` 各出现了多少次（页码没有前导零）。

**输入**：一个整数 `n`（1 ≤ n ≤ 10¹⁸）。
**输出**：10 行，依次为数字 `0` 到 `9` 的出现次数。

## 从暴力到优化

暴力：对每个 `1..n` 逐个数字拆分统计，复杂度 `O(n log n)`，n 到 1e9 时就已经不可接受。

关键观察：**固定数位**。以 `n = 259` 为例，个位（base=1）上，`1..259` 是「0~9 的循环」一共 26 轮，另有尾巴；十位（base=10）、百位同理。把 `n` 拆成：

```
n = high * base * 10 + cur * base + low
```

- 某一位上，`high` 表示比当前位更高的部分，`low` 表示更低的部分；
- 这一位出现 `d` 的次数只取决于 `cur` 与 `d` 的关系：

| 关系 | 出现次数 |
|---|---|
| `cur > d` | `(high + 1) * base` |
| `cur == d` | `high * base + low + 1` |
| `cur < d` | `high * base` |

例如 `n=259`，`d=3`，十位（base=10）：high=2，cur=5，low=9 → `cur>3`，该位贡献 `(2+1)*10=30`（30~39 的十位 3 共 10 次、130~139、230~239）。

## 对数字 0 的特判

0 不能作为最高位出现。对 `d=0`：

- `high == 0`：这一位全是前导零，跳过；
- `cur > 0`：`high * base`（少一个完整轮次：最高位不能是 0）；
- `cur == 0`：`(high - 1) * base + low + 1`。

## 正确性要点

1. 把 `1..n` 按「高位部分固定」分成 `high + 1` 组，前 `high` 组每组完整覆盖 `base` 次，末组为尾部；
2. `cur` 与 `d` 比较的三分支分别对应「完整组 + 尾部」「完整组」「少一组」；
3. 0 的修正只影响最高位（`high==0`），恰好是前导零的来源。

## 复杂度

- 时间 `O(log₁₀ n)`，空间 `O(1)`；
- `n = 10¹⁸` 时 C++ `long long` 足以容纳计数（每位数出现次数 < 9.2e18）。

## 一题多解对比

| 解法 | 时间 | 说明 |
|---|---|---|
| 逐位公式（主解） | `O(log n)` | `cpp/solution.cpp`、`python/solution.py` |
| 数位 DP（参考解） | `O(log n · 状态)` | `tests/brute.py` 中实现，与主解独立，用于验证大 n |
| 朴素枚举（参考解） | `O(n log n)` | 只用于小 n 自检 |

## 易错点与边界

- `n = 0`：答案全 0（本仓库样例 `zero`）；
- `d = 0` 且 `cur == 0`：少减一组，写成 `(high-1)*base+low+1`；
- `base * 10` 在 n 接近 1e18 时溢出：C++ 版本用 `base > n/10` 与 `LLONG_MAX/10` 双重保护；
- 只统计到 n，不统计 0 页。
