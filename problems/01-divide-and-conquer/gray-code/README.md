# 2-14 格雷码

> 分类：分治 · 位运算　|　来源：课程实验报告 2-14　|　难度：入门

## 题目

Gray 码是长度为 `2^n` 的序列：元素互不相同，每个是 n 位 0/1 串，**相邻元素只有一位不同**。对给定 n 构造一组。

**输入**：正整数 n（1 ≤ n ≤ 20）。
**输出**：`2^n` 行，每行一个 n 位 0/1 串。

## 两个方向

### 思路一：分治镜像（理解构造）

n 位格雷码 = 「0 + G(n-1) 正序」拼接「1 + G(n-1) 逆序」。

- 基线：n=1 为 `0, 1`；
- 前半部分相邻性由归纳成立；后半是前半的镜像，相邻性同样成立；
- 接缝处：前半最后一个是 `0 + G(n-1)最后一个`，后半第一个是 `1 + G(n-1)最后一个`，只差最高位。

### 思路二：位运算公式（实现最简）

第 i 个码字为

```
G(i) = i ^ (i >> 1)
```

为什么等价：`i` 与 `i>>1` 只在「从某一位到最低位全为 1、下一位为 0」的进位处不同一位；遍历 i 时恰好就是反射格雷码的顺序。

## 正确性要点

- 相邻性：镜像构造归纳；位公式则是「i 与 i+1 只翻转一个位」的等价位运算事实；
- 互异性：`i ^ (i>>1)` 在 `[0, 2^n)` 上是双射（逆变换逐位由高到低恢复）。

## 复杂度

- 时间 `O(n · 2^n)`（输出本身就要写 `n·2^n` 个字符），空间：位公式 `O(1)` 额外；镜像构造 `O(2^n)` 存储。

## 一题多解对比

| 解法 | 时间 | 空间 | 特点 |
|---|---|---|---|
| 位运算公式（主解） | `O(n·2^n)` | `O(1)` | 代码最短，无需递归 |
| 分治镜像（备选） | `O(n·2^n)` | `O(2^n)` | 直接体现“分治构造”，面试讲解清楚 |

## 易错点与边界

- n=1 时输出两行；递归实现注意基线；
- `1<<n` 用 64 位（n=20 时约 104 万行，用 `long long`/Python 无溢出问题）；
- 输出按二进制补足到 n 位（`format(g, '0{n}b')` / 从高位到低位逐位输出）。

## 复习要点

> 格雷码 = 二进制反射：`G(i)=i^(i>>1)`；忘记公式时用「前加 0 正序 + 前加 1 逆序」现场推。

## 关联与延伸

- 汉诺塔、位掩码枚举、状态编码（相邻状态只翻一位）都常用格雷码；
- 反向：给定格雷码求二进制（逐位前缀异或）。
