# 选做 2-1 众数

> 分类：分治 · 计数　|　来源：课程实验报告（选做 2-1）　|　难度：入门

## 题目

给定含 n 个元素的多重集合，元素的重数 = 出现次数，重数最大的元素称众数。求众数及其重数。

**输入**：第一行 n；第二行 n 个整数。
**输出**：第一行众数的值，第二行其重数。

**约定**：若存在多个众数（重数并列最大），输出**数值最小**的那个，保证答案确定。

## 思路

- **排序 + 扫描**：排序后相同元素连续，O(n log n)，一次遍历找最长连续段；
- **哈希计数**：O(n) 平均，适用于值域大、n 大；
- **分治雏形**：排序取中位数，向两侧扩展到整个等于中位数的区间，再递归两侧（跳过长度不足当前最优的区间）——实验报告中的做法，本质仍是排序 + 剪枝。

## 正确性要点

- 排序后同一值的元素必然连续，连续段长度即重数；
- 并列时取数值最小的一个：扫描顺序从小到大，只在**严格更大**时替换，自然保留小值。

## 复杂度

| 解法 | 时间 | 空间 |
|---|---|---|
| 排序 + 扫描（主解） | `O(n log n)` | `O(n)` |
| 哈希计数（备选） | `O(n)` 平均 | `O(n)` |

## 一题多解对比

| 解法 | 说明 |
|---|---|
| 排序 + 扫描 | 最稳，额外空间小，实现简单 |
| 哈希计数 | 大数据量更快，但哈希在最坏情况退化 |
| 分治 + 中位数剪枝 | 教学价值大于工程价值；注意剪枝条件要与“当前最优”比较 |

## 易错点与边界

- 多个众数并列：必须约定确定性规则（本仓库取最小）；
- n=0：约定输出 `0 0`；
- 值域：用 `long long`（int 也行，按题意）；
- 分治写法的剪枝：若某段长度 ≤ 当前最优重数，直接跳过，否则复杂度会退化。

## 关联与延伸

- 多数元素（Boyer–Moore 投票，保证出现 > n/2）；
- 区间众数（线段树/分块）；
- 频次 Top-K（堆 / 快速选择）。
