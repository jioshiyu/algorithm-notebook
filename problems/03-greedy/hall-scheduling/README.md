# 4-1 会场安排问题

> 分类：贪心 · 区间调度　|　来源：课程实验报告 4-1　|　难度：中等

## 题目

有 n 个活动，每个活动占用区间 `[start, end)`（首尾相接不算冲突）。用最少的会场安排全部活动，并给出每个活动的会场编号。

**输入**：n；随后 n 行，每行 `start end`。
**输出**：第一行最少会场数 k；第二行 n 个整数（活动 i 的会场编号 1..k）。

## 思路

按开始时间排序，用最小堆维护「每个会场的最早空闲时刻」：

- 堆顶的 `end <= 当前 start`：复用该会场（pop 后 push 新的空闲时刻）；
- 否则：新开一个会场。

## 正确性要点

1. **答案 = 任意时刻的最大重叠数**（区间图的团数）：任何时刻同时进行的活动都必须分属不同会场；
2. 贪心恰好达到这个数：按开始时间处理时，若要新开会场，说明此前所有会场的空闲时刻都 > 当前 start，即当前时刻同时有「已开会场数」个活动在进行，新开场数不会超过真实需要的最大重叠数；
3. 复用最早空闲的会场是安全的：它最“早可用”，不会挤占更晚可用的会场（交换论证：任何最优解中都存在同等方案）。

## 复杂度

- 时间 `O(n log n)`，空间 `O(n)`；
- 扫描线版本 O(n log n) 只求数量、不给分配；线性扫描版本 O(n²) 便于面试手写。

## 一题多解对比

| 解法 | 时间 | 特点 |
|---|---|---|
| 贪心 + 最小堆（主解） | `O(n log n)` | 最优且能给出具体分配 |
| 线性扫描空闲时刻（备选） | `O(n²)` | n 小时简单直白 |
| 扫描线（只求数量） | `O(n log n)` | 最小覆盖数，无法输出分配 |

## 易错点与边界

- **区间重合判定**：本仓库按 `[start, end)` 处理，`end == start` 可复用；若题目要求严格不相等，把 `<=` 改为 `<`；
- 同一开始时间先处理谁无所谓，但要保证堆里 end 最小者优先；
- 输出编号从 1 开始，且不超过 k；
- n=0 时输出 `0` 与空行。

## 复习要点

> 最少会场数 = 最大重叠数；按开始时间扫，堆顶 end ≤ start 就复用。
