# 4-7 多处最优服务次序问题

> 分类：贪心 · 调度　|　来源：课程实验报告 4-7　|　难度：中等

## 题目

n 个客户同时到达，第 i 个客户需要服务时间 `t_i`；有 s 个服务台。客户依次被服务，求使**平均等待时间**（总等待时间 / n）最小的安排，并输出每个客户的服务台与开始时刻。

**输入**：第一行 `n s`；第二行 n 个服务时间。
**输出**：第一行平均等待时间（保留两位小数）；随后 n 行：客户编号 服务台编号 开始时刻。

## 思路

两条贪心合并：

1. **最短服务时间优先（SPT）**：按 t 升序处理客户；
2. **选最早空闲的服务台**：维护 s 个服务台的“空闲时刻”，每次挑最小的。

## 正确性要点

1. **SPT 最小化总完成时间**：对任意两段相邻服务 `a > b`，交换后 `(a+b)` 的总等待不变但更早开始短作业，归纳可得总等待不增（经典交换论证）；
2. **最早空闲服务台**：若某客户被分到空闲时刻更晚的服务台，改为最早空闲者不会让任何客户更晚开始，总等待不增；
3. 两个贪心可同时取到：先定顺序，再逐个分给当前最早空闲的服务台。

## 复杂度

- 主解：排序 `O(n log n)` + 堆 `O(n log s)`；
- 备选线性扫描：`O(n² + s·n)`。

## 一题多解对比

| 解法 | 时间 | 特点 |
|---|---|---|
| 排序 + 最小堆（主解） | `O(n log n + n log s)` | 标准写法 |
| 排序 + 线性扫描服务台（备选） | `O(n²)` | 适合 s、n 较小时手写 |
| multiset 维护（原报告思路三） | `O(n log s)` | 与堆等价，C++ 里用 `multiset` |

## 易错点与边界

- 输出**平均**等待时间（总等待 / n），不是总等待；
- 浮点输出保留两位小数，比较时注意精度；
- 相同服务时间要按编号稳定排序，保证输出确定；
- s > n 时多余服务台闲置，结果以 n 个客户为准；
- 服务顺序必须保证同一服务台内服务时间非递减（否则不是最优）。

- 暴力参考解独立计算最优总等待，并与输出逐项比对；

## 复习要点

> 多机等待时间最小 = **最短作业优先** + **最早空闲服务台**。

## 关联与延伸

- 单机总完成时间最小（SPT 规则）；
- 平均完成时间 vs 平均等待时间的区别（本题是等待）；
- 加权版本：按 `t_i / w_i` 排序（Smith 规则）。
