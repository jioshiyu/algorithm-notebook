# 6-2 顶点覆盖问题（带权最小顶点覆盖）

> 分类：分支限界　|　来源：课程实验报告 6-2　|　难度：较难

## 题目

带权无向图 G=(V,E)，选顶点子集 U 使每条边至少有一个端点在 U 中，且 U 的权值和最小。

**输入**：第一行 `n m`；第二行 n 个权值；随后 m 行 `u v`。
**输出**：第一行最小权值和；第二行选中顶点编号（升序，空格分隔）。

## 思路：分支限界

- 解空间：每个顶点「选 / 不选」；
- 优先队列按**下界**升序扩展；
- 下界必须是**可采纳**的（不会高估真实剩余代价），否则会把最优解剪掉。

### 关键点：下界怎么取

❌ 错误做法：对每条未覆盖边取 `min(w_u, w_v)` 再相加。

反例：星形图，中心权值 1，两条边（中心-叶1，中心-叶2），叶子权值 100。
按错误下界：`1 + 1 = 2`；而真实最小覆盖只选中心，代价 `1`。**下界 2 > 1 不可采纳**，会剪掉最优解。

✅ 正确做法：取一组**互不相邻**的未覆盖边（贪心极大匹配），每条匹配边至少需要一个端点，代价 ≥ `min(w_u, w_v)`，且这些边不共享顶点、代价可相加：

```
bound = 当前已选权值 + Σ_{匹配边 e} min(w_e 两端)
```

## 正确性要点

1. 匹配边两两不共享顶点，覆盖它们至少需要 |匹配| 个不同顶点；
2. 每条匹配边被覆盖时，其端点权值至少为 `min(w_u, w_v)`（可能来自其它顶点? 不行——该边只有两个端点，覆盖它必须选其中之一）→ Σ 是下界；
3. 因此 `bound ≥ 当前 + 剩余真实代价 ≥ 当前 + 最优剩余`，剪枝安全。

## 复杂度

- 最坏 `O(2^n · m)`；分支限界+匹配下界在随机图上通常远小于此；
- 一般图最小权顶点覆盖是 NP-hard，本题靠小规模 + 剪枝。

## 一题多解对比

| 解法 | 时间 | 特点 |
|---|---|---|
| 分支限界（主解） | 最坏 `O(2^n·m)` | 通用，随机图快 |
| DFS 回溯 + 同一下界（备选） | 最坏 `O(2^n·m)` | 代码更短，dfs 序 |
| 二分图特例 | `O(n·m)` | Konig 定理转最大匹配 |

## 易错点与边界

- 下界不可采纳会剪掉最优（本仓库实测踩过）；
- m=0：答案 0，第二行空；
- 顶点编号 1..n；
- 权值可能为 0：`best` 初值用大数，不要用 0；
- 输出方案要与权值和自洽（checker 核对覆盖合法性）。

## 复习要点

> 分支限界三要素：**剪枝要可采纳**（下界 ≤ 真实）、**分支要覆盖全**、**优先扩展下界最小**。这题的下界用「极大匹配」而不是「逐边取 min 求和」。

## 关联与延伸

- 最大独立集 = 补图顶点覆盖；
- 二分图：Konig 定理（最小点覆盖 = 最大匹配）；
- 参数化算法（FPT，按 k 分支）与 2-近似（极大匹配）。
