# 5-3 / 选 6-4 最小重量机器设计（回溯 · DP · 分支限界 三范式对照）

> 分类：分支限界（主解）· 回溯 · DP　|　来源：课程实验报告 5-3 与选 6-4（同一题两份报告，合并）　|　难度：较难

## 题目

n 个部件，每个部件可从 m 个供应商购买；价格 `c[i][j]`、重量 `w[i][j]`。总价格不超过 d 时，使总重量最小。

**输入**：第一行 `n m d`；随后 n 行价格矩阵；再 n 行重量矩阵。
**输出**：最小总重量；第二行 n 个供应商编号（1..m）。无解输出 `No solution`。

## 三种范式（同一道题，三种解空间视角）

### 1) 回溯法（DFS 子集树）

按部件顺序 DFS，每个部件枚举 m 个供应商：

- 约束剪枝：当前价格已超过 d；
- 限界剪枝：当前重量 ≥ 已知最优。

`O(m^n)` 最坏，剪枝后通常远小。

### 2) 动态规划（价格维度）

`dp[i][j]` = 前 i 个部件、总价格恰为 j 的最小重量：

```
dp[i+1][j + c[i][k]] = min(dp[i+1][j + c[i][k]], dp[i][j] + w[i][k])
```

时间 `O(n·m·d)`，空间 `O(n·d)`；d 不太大时最快最稳。

### 3) 分支限界（主解）

优先队列按**下界** `bound = 当前重量 + 剩余部件各自最小重量之和` 升序扩展：

- 若 `bound ≥ 最优`，整枝剪掉；
- 价格超限直接剪；
- 叶子节点更新最优。

下界可采纳（每件最多只能取到的最小重量），所以第一次出队的完整解不一定是答案，但**不会错过最优**。

## 正确性要点

1. 回溯与 DP 的穷举/递推直接对应解的定义，正确性显然；
2. 分支限界：下界不超过真实完成重量 → 剪掉的枝不可能更优；价格剪枝合法（价格只增不减）；
3. 三种方法得到同一最优重量（对拍验证）。

## 复杂度对比

| 解法 | 时间 | 空间 | 适用 |
|---|---|---|---|
| 回溯 | 最坏 `O(m^n)` | `O(n)` | 小型数据、教学 |
| DP | `O(n·m·d)` | `O(n·d)` | d 适中（几千以内） |
| 分支限界 | 最坏 `O(m^n)`，实际远小 | `O(n·每层节点)` | 通用，d 可大 |

## 易错点与边界

- 价格/重量可能为 0：DP 初始 `INF` 不要用 0 当“不可达”；
- 无解要显式输出 `No solution`（价格全超 d 时）；
- 分支限界的下界不要漏掉“剩余部件”的贡献，否则会剪掉最优解；
- 输出方案要与最优重量自洽（checker 会核对 price ≤ d 且 weight = 输出值）。
