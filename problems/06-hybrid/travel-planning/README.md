# 大作业 旅行规划问题

> 分类：折半搜索 · 综合　|　来源：课程算法大作业（旅行规划）　|　难度：较难

## 题目

n 个景点，门票价格互不相同；每个景点最多去一次。要求**恰好花完** target 元，求所有景点组合。

**输入**：第一行 `n target`（1 ≤ n ≤ 40，target ≥ 1）；第二行 n 个互不相同的票价。
**输出**：第一行方案数；随后每行一个组合（景点编号升序，1-based）。

## 思路

### 折半搜索（主解）

把景点分成左右两半：

1. 左半、右半分别枚举全部 `2^(n/2)` 个子集，记录 `(和, mask)`；
2. 右半按和分组（哈希表 `sum -> masks`）；
3. 对左半每个子集，查 `target - 左和` 对应的右半子集，合并成完整方案。

复杂度 `O(2^(n/2) · n)`，n=40 时约 `2^20` 级，可行。

### 其它解法（同一题的多视角）

| 解法 | 复杂度 | 说明 |
|---|---|---|
| 枚举全部子集 | `O(2^n·n)` | n ≤ 20 最直观（`alt_enum.cpp`） |
| 回溯 + 剪枝 | 最坏 `O(2^n)`，剪枝后小 | 票价为正，和超过 target 即剪（`alt_backtrack.cpp`） |
| 布尔 DP | `O(n·target)` | target 不大时可行，还原所有方案需额外处理 |
| 分支限界 | 最坏 `O(2^n)` | 本题无自然下界，收益有限 |

## 正确性要点

- 子集与「选/不选」一一对应；
- 左右半拼接覆盖所有子集，且和恰好为 target；
- 正票价保证：和超过 target 的分支不可能再回到 target（剪枝合法）。

## 易错点与边界

- target 不可达 → 输出 0，无组合行；
- 空集不是解（target ≥ 1）；
- 输出组合要按景点编号升序，避免同一方案以不同顺序重复；
- n 较小时枚举即可，n 大必须折半；
- 方案数可能很多，注意输出量。
