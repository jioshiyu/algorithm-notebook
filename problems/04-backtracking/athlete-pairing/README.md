# 5-4 运动员最佳配对

> 分类：回溯 · 状压 DP　|　来源：课程实验报告 5-4　|　难度：中等偏难

## 题目

n 名男运动员、n 名女运动员。矩阵 P：`P[i][j]` 为男 i 与女 j 搭档时男方的竞赛优势；矩阵 Q：`Q[i][j]` 为女 i 与男 j 搭档时女方的竞赛优势。男 i 与女 j 配对的总优势为 **`P[i][j] * Q[j][i]`**（注意 Q 的下标是 `[j][i]`）。求总优势最大的配对方案。

**输入**：n；n 行 P；n 行 Q。
**输出**：第一行最大总优势；第二行 n 个整数，男 i 配对的女运动员编号。

## 思路

### 状压 DP（主解）

`dp[mask]` = 已给前 `popcount(mask)` 名男运动员配完、占用女运动员集合为 `mask` 时的最大总优势：

```
dp[mask | (1<<j)] = max(dp[mask] + P[i][j] * Q[j][i])   // i = popcount(mask)
```

时间 `O(n·2^n)`，空间 `O(2^n)`；`pre[mask]` 记录最后一次选的 j 以还原方案。

### 回溯 + 乐观上界（备选）

按男运动员顺序枚举未占用的女运动员；剪枝上界：剩余每个男运动员都取“当前未占用女运动员中最大优势”之和（允许重复，故是真实值上界），若 `当前和 + 上界 ≤ 已知最优` 则剪枝。

## 正确性要点

1. 每名男运动员恰好配一名女运动员 → 状态只需记录「已占用的女性集合」，`popcount(mask)` 即下一个男运动员编号；
2. 转移枚举所有可用女性，覆盖全部方案；
3. 回溯上界 ≥ 真实可达值 → 剪枝安全。

## 复杂度

| 解法 | 时间 | 空间 | 适用 |
|---|---|---|---|
| 状压 DP（主解） | `O(n·2^n)` | `O(2^n)` | n ≤ 15 左右 |
| 回溯 + 上界（备选） | 最坏 `O(n!)`，剪枝后远小 | `O(n)` | n 较小 |
| 匈牙利算法（扩展） | `O(n³)` | `O(n²)` | 最大权完美匹配，n 更大 |

## 易错点与边界

- **Q 的下标是 `Q[j][i]`**（女 j、男 i），不是 `Q[i][j]`——这是本报告最容易错的一点；
- 优势可能为负：DP 初值用 `-inf` 而不是 0；回溯的最优初值也用最小负数；
- 输出的是「每名男运动员配的女运动员编号」，不是配对对数；
- n=1 直接输出 `P[0][0]*Q[0][0]`。

> 最大权完美匹配：n 小用**状压 DP（mask 记录女运动员占用）**；n 大用**匈牙利算法**；回溯只需记住「乐观上界可采纳」。
