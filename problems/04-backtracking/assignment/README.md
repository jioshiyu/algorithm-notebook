# 选 5-13 工作分配问题

> 分类：回溯 · 状压 DP　|　来源：课程实验报告（选 5-13）　|　难度：中等偏难

## 题目

n 个人、n 件工作，`c[i][j]` 表示第 i 人做第 j 件工作的费用。每人恰好做一件、每件恰好由一人做，使总费用最小。

**输入**：n；n 行 n 列费用矩阵。
**输出**：第一行最小总费用；第二行 n 个整数（第 i 人做的工作编号）。

## 思路

### 状压 DP（主解）

`dp[mask]` = 已给前 `popcount(mask)` 个人分配完、占用工作集合为 `mask` 时的最小费用：

```
dp[mask | (1<<j)] = min(dp[mask] + c[i][j])   // i = popcount(mask)
```

时间 `O(n·2^n)`，空间 `O(2^n)`；`pre[mask]` 记录最后一次选的工作以还原方案。

### 回溯 + 剩余最小费用下界（备选）

按人顺序枚举未占用的工作；剪枝：剩余每个人取「未占用工作中的最小费用」之和（允许重复，故是下界），`当前 + 下界 ≥ 已知最优` 时剪枝。

## 正确性要点

1. 每件工作恰好一人做 → 状态只需记录占用集合；
2. `popcount(mask)` 即下一个人，保证顺序不重复；
3. 回溯下界 ≤ 真实剩余费用（每人至少要付其可选最小费用）→ 剪枝安全。

## 复杂度

| 解法 | 时间 | 空间 | 适用 |
|---|---|---|---|
| 状压 DP（主解） | `O(n·2^n)` | `O(2^n)` | n ≤ 15 左右 |
| 回溯 + 下界（备选） | 最坏 `O(n!)` | `O(n)` | n 小 |
| 匈牙利算法（扩展） | `O(n³)` | `O(n²)` | 指派问题（Assignment Problem）标准解 |

## 易错点与边界

- 费用可能为 0 或负数？本仓库按非负处理；若为负，DP 初值不要用 0 表示不可达；
- 输出第二行是「每个位置的人对应的工作编号」，不是工作对应的人；
- n=1 直接输出 `c[0][0]` 与 `1`。

## 复习要点

> 「n 人 n 事、一一对应」= 指派问题：n 小用**状压 DP**，n 大用**匈牙利算法**；回溯加「剩余最小费用」下界即可剪枝。
