# 3-1 最长递增子序列（LIS）

> 分类：动态规划 · 贪心+二分　|　来源：课程实验报告 3-1　|　难度：中等

## 题目

给定长度为 n 的整数序列，求**最长严格递增子序列**的长度，并输出任意一条。

**输入**：第一行 n（0 ≤ n ≤ 1e6）；第二行 n 个整数。
**输出**：第一行：长度 L；第二行：L 个整数，表示一条 LIS（空格分隔）。

## 从 O(n²) 到 O(n log n)

### 基准：DP

`dp[i]` = 以 `a[i]` 结尾的 LIS 长度：`dp[i] = 1 + max{dp[j] : j < i, a[j] < a[i]}`。时间 `O(n²)`。

### 优化：贪心 + 二分

维护 `tail[k]`：**长度为 k+1 的递增子序列的最小结尾值**。

- `tail` 天然单调递增（同样长度，结尾越小越“有前途”）；
- 对 `a[i]` 在 `tail` 中二分找第一个 `≥ a[i]` 的位置 `pos`（`lower_bound`，严格递增用 lower_bound）；
- `pos == 长度`：追加，LIS 长度 +1；否则替换 `tail[pos] = a[i]`；
- 同时记 `tailIdx[pos] = i`、`pre[i] = tailIdx[pos-1]`，用于最后还原序列。

## 正确性要点

1. **tail 不变式**：处理完前 i 个元素后，`tail[k]` 是长度为 k+1 的递增子序列的最小结尾值；
2. 替换不破坏不变式：用更小结尾替换同长度结尾，只会让后续更容易接上；
3. 长度正确：`tail` 的长度就是当前 LIS 长度（每个长度都真实存在）；
4. 还原正确：`pre[i]` 指向长度恰好 `pos` 的那条前缀的末尾，链长等于 `pos+1`。

## 复杂度

- 时间 `O(n log n)`，空间 `O(n)`；
- n = 1e6 时 C++ 版 < 0.2s。

## 一题多解对比

| 解法 | 时间 | 空间 | 适用 |
|---|---|---|---|
| 贪心 + 二分（主解） | `O(n log n)` | `O(n)` | 通用，大 n |
| O(n²) DP（备选） | `O(n²)` | `O(n)` | 讲解状态、面试手写 |
| 树状数组维护前缀最大值 | `O(n log n)` | `O(n)` | 可扩展到「带权 LIS」「二维偏序」 |

## 易错点与边界

- **严格**递增用 `lower_bound`；非递减用 `upper_bound`，别混；
- n=0 输出长度 0 与空行；
- 有重复值时 `a[j] < a[i]` 才转移；
- 还原时不要直接输出 `tail`（`tail` 只是“结尾候选”，不是一条真实子序列）；
- 有多条 LIS 时输出任意一条即可（本仓库 `tests/checker.py` 校验语义：长度、严格递增、是输入子序列）。

## 复习要点

> LIS 的核心状态是「每种长度对应的最小结尾」；`lower_bound` 找位置、`pre` 还原序列。
