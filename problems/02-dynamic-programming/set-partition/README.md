# 2-7 集合划分问题（Bell 数）

> 分类：动态规划 · 递推　|　来源：课程实验报告 2-7　|　难度：中等

## 题目

n 个元素的集合 `{1,2,...,n}` 可以划分为多少个非空子集族？即求 **Bell 数** `B(n)`。

**输入**：非负整数 n（0 ≤ n ≤ 25）。
**输出**：`B(n)`。

## 思路：第二类 Stirling 数

记 `S(n,k)` 为把 n 个元素划分为**恰好 k 个非空子集**的方案数（第二类 Stirling 数），则

```
B(n) = Σ_{k=0..n} S(n,k)
```

对 `S(n,k)` 按「第 n 个元素是否单独成块」分类：

- 单独成块：前 n-1 个元素划成 k-1 块 → `S(n-1,k-1)`；
- 并入已有块：前 n-1 个元素划成 k 块，再把第 n 个元素放进其中一块（k 种选择）→ `k · S(n-1,k)`。

因此 `S(n,k) = S(n-1,k-1) + k·S(n-1,k)`，边界 `S(0,0)=1`，其余 0。

用**一维滚动数组**倒序更新即可，空间 `O(n)`。备选解用 **Bell 三角**（同样 `O(n²)`）。

## 正确性要点

1. 分类不重不漏：n 所在块大小 ≥2 或 =1，两类互斥且覆盖全部；
2. 第二类情况中「放进哪一块」恰有 k 种；
3. 边界 `S(0,0)=1` 保证空集恰有 1 种划分（空划分），从而 `B(0)=1`。

## 复杂度

- 时间 `O(n²)`，空间 `O(n)`；
- `B(n)` 增长极快：`B(25) ≈ 4.64e18`，在 64 位整数内；`B(26)` 溢出，需要大整数或取模。

## 一题多解对比

| 解法 | 时间 | 空间 | 说明 |
|---|---|---|---|
| Stirling 滚动行（主解） | `O(n²)` | `O(n)` | 最直白，顺带得到每块的方案数 |
| Bell 三角（备选） | `O(n²)` | `O(n)` | 只需一次三角形推进 |
| 递推 `B(n)=Σ C(n-1,k)B(k)` | `O(n²)` | `O(n)` | 组合数直接算，适合只求单个 B(n)（作为参考解） |

## 易错点与边界

- n=0 输出 1（空集划分）；
- 滚动更新必须**倒序** k，否则 `S(k-1)` 被本行覆盖；
- 64 位上界 25，超过要用 `boost::multiprecision` 或 Python 大整数。

## 复习要点

> 集合划分 = 第二类 Stirling 数求和；递推 `S(n,k)=S(n-1,k-1)+k·S(n-1,k)`。

## 关联与延伸

- 整数拆分 / 划分数 p(n)（元素不可区分）；
- 第二类 Stirling 数的显式公式 `S(n,k)=1/k! Σ (-1)^i C(k,i)(k-i)^n`；
- Bell 数的指数生成函数 `e^(e^x-1)`。
