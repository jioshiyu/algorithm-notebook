# 选做 3-0 硬币问题（多重背包求最少硬币数 + 方案）

> 分类：动态规划 · 多重背包　|　来源：课程实验报告（选做 3-0）　|　难度：较难

## 题目

n 种面值 `T[i]`，每种最多 `coins[i]` 枚；凑出金额 m，使硬币数最少。

**输入**：第一行 n；第二行 n 个面值；第三行 n 个可用枚数；第四行 m。
**输出**：第一行最少硬币数；随后每行 `面值 枚数`（按面值升序）；凑不出输出 `No solution`。

## 思路

### 朴素多重背包

`dp[i][j]` = 前 i 种面值凑出 j 的最少硬币数：

```
dp[i][j] = min_{0<=k<=coins[i], k*v<=j} dp[i-1][j-k*v] + k
```

`O(n·m·cnt)`，可行但慢，且需要二维表才能稳定还原方案。

### 单调队列优化（主解）

对每种面值 v，按余数 r 分组（`j = r + x·v`），令 `y = x-k`：

```
newdp[j] = x + min_{y in [x-cnt, x]} (dp[r+y·v] - y)
```

`dp[r+y·v] - y` 在滑动窗口内取最小值 → 单调队列，每种面值 `O(m)`，总 `O(n·m)`；同时记录每个状态用了 k 枚该面值，天然可还原方案。

## 正确性要点

1. 余数分组后，每种面值的使用量变成「窗口内取最优」，窗口大小 = 可用枚数；
2. `newdp[j] = dp[r+y*v] + (x-y)`，其中 `x-y` 就是使用的枚数；
3. 记录 `used[i][j]` 后倒推即可得到方案。

## 复杂度

| 解法 | 时间 | 空间 |
|---|---|---|
| 单调队列（主解） | `O(n·m)` | `O(n·m)`（还原方案） |
| 二进制拆包 + 0/1 背包 | `O(m·Σlog cnt)` | `O(m)` |
| 朴素 k 枚举（备选/暴力） | `O(n·m·cnt)` | `O(n·m)` |

## ⚠️ 二进制拆包的还原陷阱（本仓库实测踩坑）

用「二进制拆包 + 一维 dp + 只记录 `(来的状态, 物品)`」还原方案时，会出现**同一个拆分物品被用两次**的假方案：

- 原因：`par[j]` 指向的是「金额」而不是「某个物品在第几轮处理时的状态」；当中间状态 `dp[j-v]` 在后续轮次被更优值覆盖后，还原路径会读到新版本，导致物品重复使用；
- 该错误只在「需要输出方案」时暴露（只求最少枚数时 dp 是正确的）；
- 规避：用二维层 DP（上表方案）或本仓库的单调队列版本，把「每层用了多少」记录下来。

## 易错点与边界

- m=0：输出 0 枚，无使用明细；
- 某种面值数量为 0：跳过；
- 面值大于 m：跳过；
- 无解要输出 `No solution`；
- 输出按面值升序、只输出使用枚数 > 0 的。

## 复习要点

> 多重背包 + 方案 = 单调队列（或分层 DP）；**一维 dp 的父指针在「金额状态会被覆盖」时不可靠**。

## 关联与延伸

- 完全背包（每种无限）— 正序一维 dp；
- 找零方案计数（完全背包计数版）；
- 混合背包、二维费用背包。
