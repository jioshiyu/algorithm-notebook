# 3-4 数字三角形

> 分类：动态规划　|　来源：课程实验报告 3-4　|　难度：入门

## 题目

给定 n 行数字三角形（第 i 行 i 个数），从顶至底走一条路径（每步只能走到下一行同列或右一列），使路径上数字之和最大。

**输入**：第一行 n；接下来 n 行，第 i 行 i 个整数。
**输出**：第一行最大和；第二行一条达到最大和的路径（n 个数，空格分隔）。

## 思路

### 自底向上（主解）

`dp[i][j] = a[i][j] + max(dp[i+1][j], dp[i+1][j+1])`

从最后一行往上推，`dp[0][0]` 即答案；再自顶向下，每步走向 `dp` 较大的子格即可还原路径。

### 自顶向下（备选）

`dp[i][j] = a[i][j] + max(dp[i-1][j-1], dp[i-1][j])`，最后在底行取最大值，再自底向上按转移等式还原路径。

## 正确性要点

- 最优子结构：顶点的最优路径必然包含子三角形的最优路径；
- 自底向上没有“从哪来到哪去”的边界分支（越界交给 max），比自顶向下少一堆判断；
- 路径还原：`dp` 的大小关系唯一确定“下一步走哪”（相等时任选，仍是合法最优路径）。

## 复杂度

- 时间 `O(n²)`，空间 `O(n²)`；只求最大值时空间可压到 `O(n)`，但难以还原路径（本题需还原）。

## 一题多解对比

| 解法 | 时间 | 空间 | 特点 |
|---|---|---|---|
| 自底向上（主解） | `O(n²)` | `O(n²)` | 边界最简、还原自然 |
| 自顶向下（备选） | `O(n²)` | `O(n²)` | 更贴近“从起点出发”的直觉，边界判断多 |

## 易错点与边界

- 允许负数：最大值初始不要用 0 当“空路径”；
- n=1 时直接输出该数；
- 路径还原要按“下一步”而不是“上一行”，否则容易错位；
- 多组最优路径时输出任意一条（`tests/checker.py` 校验和与走法合法性）。

## 复习要点

> 数字三角形 = 路径 DP 模板题：**自底向上**写转移，**按 dp 大小**还原路径。
