# 分类地图（按算法思想）

> 同一道题可能有多种范式，目录只放一处（主解所在分类），其它范式在题解与下表交叉列出。

## 01 分治 / 数位统计

| 题目 | 关键观察 | 目录 |
|---|---|---|
| 统计数字问题 | 逐位统计 0-9 出现次数，特判 0 | [count-pages](../problems/01-divide-and-conquer/count-pages/) |
| 格雷码 | n 位由 n-1 位镜像拼接；或 `i ^ (i>>1)` | [gray-code](../problems/01-divide-and-conquer/gray-code/) |
| 众数 | 排序后取最长连续段；并列取最小 | [majority](../problems/01-divide-and-conquer/majority/) |
